# CLAUDE.md

## Project Overview

AI Spend Audit is a web application designed to help startups and teams analyze their AI subscription costs, identify unnecessary spending, and discover more cost-efficient alternatives. The platform generates actionable audit summaries and optimization recommendations based on company usage patterns.

---

## Tech Stack

- Next.js
- React
- Tailwind CSS
- JavaScript
- OpenRouter / OpenAI API
- Vercel Deployment

---

## Core Features

- AI subscription cost analysis
- Savings estimation dashboard
- AI-generated optimization summaries
- Responsive modern UI
- Audit form with company/team inputs
- Cost comparison recommendations
- CAPTCHA verification support
- Deployment-ready architecture
